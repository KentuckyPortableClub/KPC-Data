Park page reader on your own PC.
You need Python 3.10 or newer. Nothing else to install for a basic run.
Double-click run-park-pages.bat on Windows, or run-park-pages.sh on Mac or Linux.
It asks one question: Which state? Leave the answer blank to continue the list.
It prints plain sentences while it reads.
When it finishes, send the zip it names to the chat.
If something goes wrong, the details are in run-log.txt next to this file.
A PDF is clearer when pypdf is installed. The script says so in one line when it is missing.
A page that builds itself needs Playwright. The script says so in one line when it is missing.
Do not put a password or a key in this folder.
