# Outside research job: second look at 23 park outlines (Kentucky Portable Club, 18 Nov 2026)

You have open internet, which our own graders lack. Many agency sites (nps.gov, fws.gov, fs.usda.gov, state park sites) would
not open for them. This job is mostly LOOKING THINGS UP ON OFFICIAL SOURCES.

Files:
1. GRADER-PROMPT.md: the rules. Read all of it first.
2. packet-second-look-01-01.md: 25 parks, each with a line-up of map records (A, B, C ...).
3. packet-second-look-01-01.answers-template.csv: fill it in. One line per candidate, columns exactly
   ref,candidate,verdict,source,note. Save it as packet-second-look-01-01.answers.csv.

For each park, please:
- open the park's own website (given in the packet), then the managing agency's page or official map;
- give every candidate YES / BIGGER / NO / UNSURE with the address of the page or map you actually opened;
- in 'note', put the official acreage and the exact sentence it comes from when you find one ("The 2,400-acre park ...").

Rules that matter most: a similar name is not evidence; no source = UNSURE; never use Wikipedia, POTA, KPC or hobby maps
as the only source. Some parks are tests with known answers.

Return: the filled answers.csv only. Change no other file.
