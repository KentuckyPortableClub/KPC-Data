# Status-only close matches

A list of park IDs whose current join is a clean close match: the held record's own name matches the park, and the pin sits inside that land or within 100 m of it.

This file is IDs and counts only. It is not applied automatically. It does not move a pin, rewrite a key, or write an override. Writing joins from this list later would be a signed rule change.

24 Nov 2026 list: `nov24-close-matches.json` (1,025 parks still to status-confirm; 55 already confirmed by KPC-Links #365 are listed separately). See that file for the exclusions and the counts, including how many dropped because the held record's name did not match.
